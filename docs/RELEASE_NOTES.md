# Lumen 2.2.4 · [저장]·[새 사진]이 화면 밖으로 밀려 사라지던 문제

v2.2.3에서 **"다른 사진 불러오기 버튼이나 저장 버튼이 없지 않아?"** 하신 그 두 버튼입니다. 버그가
맞았습니다. 앱에서 사라진 게 아니라 **화면 오른쪽 밖으로 밀려나 있어서** 보이지 않았습니다.

## 무엇이 문제였나

`app/src/main/java/com/plenuen/lumen/ui/EditorScreen.kt` 하단 도구 줄이 모든 버튼을 **가로 스크롤
없이 한 줄에** 넣고 있었습니다.

```
[✨ 자동] [자동 수평·수직] [필름 룩] [슬라이더]      ← 여기까지가 화면 폭을 다 씀
[저장] [+ 다른 사진]                                ← 화면 밖으로 밀려 잘림
```

- v2.2.0에서 `[✨ 자동]`이 앞에 붙으면서 왼쪽 네 버튼만으로 **스마트폰 가로 폭(약 360~411dp)을
  넘어섰습니다.** `Row`는 넘치는 자식을 줄이지 않고 그대로 오른쪽으로 배치하므로, 뒤에 있던 `[저장]`과
  `[다른 사진]`은 화면 밖에 그려졌습니다. 눌러서 안 되는 게 아니라 아예 보이지 않았습니다.
- `[다른 사진]`은 `+` 아이콘만 있어서, 설령 보였더라도 무엇인지 알아보기 어려웠습니다.

## 어떻게 고쳤나

하단 줄을 **두 구역**으로 나눴습니다.

- **왼쪽(스크롤 구역)** — 보정 도구 4개(`✨ 자동` · `자동 수평·수직` · `필름 룩` · `슬라이더`)만
  `Modifier.weight(1f).horizontalScroll(...)`로 들어갑니다. 화면이 좁으면 이 도구들만 옆으로 밀립니다.
- **오른쪽(고정 구역)** — `[+ 새 사진]`(아이콘+글자)과 `[저장]`은 스크롤 밖에 두어 **어떤 화면 폭에서도
  제자리에 남습니다.** `weight(1f)`는 남는 폭만 가져가므로, 오른쪽 두 버튼의 자리는 항상 먼저
  확보되고 왼쪽 도구가 그만큼 좁아집니다.

이제 좁은 360dp 화면에서도 `[새 사진]`·`[저장]`이 항상 보이고, 자주 쓰는 `✨ 자동`은 왼쪽 끝에
그대로 있습니다. 회귀 방지 테스트 `EditorLayoutTest`가 **저장·새 사진이 다시 스크롤 구역으로
들어가면 실패**하도록 배치를 고정합니다.

## 검증

- 단위 테스트 **154개 전부 통과**(기존 153 + 신규 1: `EditorLayoutTest`).
- `versionCode 224` / `versionName 2.2.4`, `apksigner verify` → **APK Signature Scheme v2 통과**.

## 남은 확인

폰에서 하단 줄을 봐 주세요. **오른쪽에 `[+ 새 사진]`과 `[저장]`이 나란히 보이면** 고쳐진 것입니다.
왼쪽 보정 도구는 손가락으로 옆으로 밀면 나머지가 나옵니다. 글씨 크기를 크게 키운 설정에서도 두
버튼이 겹치지 않는지 같이 봐 주시면 좋겠습니다. 이상이 있으면 화면 캡처와 함께 알려 주세요.
