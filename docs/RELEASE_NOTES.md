# Lumen 2.0 · 자연어 비파괴 사진 보정

이전 FilmCam(Lut-studio) 코드를 대체한 2.0 빌드입니다. 필름·카메라 3D LUT 57종은 그대로 옮겨 왔습니다.

## 새로 생긴 것

- **비파괴 편집**: 원본은 읽기 전용, `EditRecipe` + 히스토리만 변경. 되돌리기/다시 실행/초기화,
  길게 눌러 원본 비교, 수동 슬라이더, 원본 해상도 새 파일 저장.
- **GLES 3.0 파이프라인**: 프리뷰와 저장이 같은 셰이더를 사용. 톤 7종, 색감 10종, 디테일 8종,
  피사체 강조, 3D LUT + 강도.
- **자동 수평·수직**: 구조 텐서 투표로 기울기를 추정하고(수평·수직 동시), 각도에 맞춘 내접 크롭으로
  검은 테두리 없이 곧게 세웁니다. 원터치 버튼 + 0.1° 슬라이더 + "수직 원근" 보정.
- **자연어 엔진**: 17개 정밀 매핑 + 11개 카테고리 + 대표 룩 + 시간·계절·공기·기억·매체·미적 평가,
  강도 부사와 "더/덜/절반만/취소/초기화" 대화 제어, 필름 이름 인식.
- **로컬 LLM**: Qwen2.5 0.5B/1.5B(q8)를 MediaPipe LLM Inference로 온디바이스 실행.
  APK에는 넣지 않고 첫 사용 시 진행률과 함께 내려받습니다.
- **57종 필름 룩**: Kodak 24 · Fujifilm 14 · Agfa 7 · Ilford 1 · Leica 6 · Ricoh GR 5,
  이전 빌드와 LUT 바이트 동일(SHA-256 테스트).

## 검증

- 단위 테스트 39개 통과 (`gradle :app:testDebugUnitTest`)
- debug / release APK 빌드 및 `apksigner verify` 통과
- 프리뷰·저장 셰이더 GLSL ES 3.00 컴파일 검증(glslangValidator)

## 실기기 확인 필요

- GPU에서의 프리뷰 렌더링과 원본 해상도 저장 결과 일치
- 자동 수평·수직이 실제 기운 사진에서 동작하는지
- 로컬 LLM 첫 다운로드와 추론 속도
