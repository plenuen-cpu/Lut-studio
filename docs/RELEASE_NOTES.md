# Lumen 2.1.0 · 영역 마스킹과 8색 HSL 핀셋

"1+2도 반영해줘" — 요청한 두 가지를 그대로 넣었습니다. ① **온디바이스 영역 분리 마스킹**으로
인물·배경·하늘을 따로 보정하고, ② **8색 HSL**로 색 대역마다 색조·채도·밝기를 핀셋처럼 조절합니다.
둘 다 자연어로도, 슬라이더로도 됩니다.

## 1. 영역 마스킹 (인물·피사체 · 배경 · 하늘)

- **모델**: MediaPipe ImageSegmenter + **`selfie_multiclass_256x256.tflite`**(16MB)를 APK assets에 번들.
  클래스는 배경·머리카락·몸 피부·얼굴 피부·옷·기타 6개이고, 배경(0)을 뺀 나머지를 피사체로 씁니다.
  네트워크를 쓰지 않습니다(모델 다운로드 없음).
- **하늘**: 이 모델은 하늘을 모르므로 사진에서 직접 찾습니다 — 색(파랑~중성)·밝기·상단 위치·
  행 단위 비율(그 줄의 28% 이상이 하늘스러워야 인정)로 점수를 만들고 피사체를 빼냅니다.
  그래서 파란 셔츠나 벽이 하늘로 올라가지 않습니다.
- **페더링**: 피사체·하늘 모두 박스 블러 3회(가우시안 근사)로 경계를 번지게 했습니다. 모델의 256px
  출력은 최근접으로 사진 크기에 맞춰 올린 뒤 블러합니다.
- **전달**: 마스크는 GL 텍스처 한 장(R=피사체, G=하늘)으로 셰이더에 들어가고, 배경은 `1 − R − G`
  로 계산됩니다. 프리뷰와 원본 해상도 저장이 **같은 생성기·같은 방식**을 쓰므로 화면과 파일이 같습니다.
- **폴백**: 모델을 못 열거나 마스크를 읽지 못하면 테두리 색과의 거리 + 중앙 가중치로 피사체를
  추정합니다. 슬라이더 패널 `영역 보정` 탭에 `MediaPipe selfie_multiclass · 인물 분리` 또는
  `색·위치 기반 폴백`으로 표시됩니다.
- **파라미터 14개**: 피사체(밝기·채도·색온도·선명도), 배경(밝기·채도·색온도·선명도·흐림),
  하늘(밝기·채도·색온도·파랑), 영역 마스크 켜고 끄기.
- **미리보기**: `마스크 보기` 칩 → 피사체는 주황, 하늘은 파랑으로 칠해집니다(저장에는 안 들어감).
- **자연어**: "인물만 화사하게", "피사체만 선명하게", "주제만 밝게", "배경만 차분하게",
  "배경만 어둡게", "배경 채도 빼줘", "배경만 부드럽게", "하늘만 파랗게", "하늘만 깊게",
  "하늘 날아간 거 살려줘" → 영역 파라미터만 바뀌고 사진 전체 노출·채도는 그대로입니다.
  "인물 사진", "틸앤오렌지"처럼 룩 이름 안에 든 낱말은 가로채지 않고, "하늘이 날아가지 않게"
  같은 부정은 기존대로 제한으로 읽습니다.
- **로컬 LLM**: 프롬프트에 "영역을 말했을 때만 그 영역 파라미터를 쓴다" 규칙과 예시 3개를 넣고,
  자연스러운 한국어 키("인물 밝기", "배경 채도", "하늘")도 받아들이게 했습니다.

## 2. 8색 HSL 핀셋

- 대역: **빨강(0°) · 주황(30°) · 노랑(60°) · 초록(120°) · 청록 · 파랑 · 보라 · 자홍**.
- 셰이더가 픽셀을 HSL로 바꾸고, 대역마다 **코사인 창**으로 겹쳐 섞은 뒤 다시 RGB로 돌립니다.
  각 대역은 자기 중심에서 1, 이웃 중심에서 0이라 **가중치 합이 색상환 전체에서 1**이고 색 경계가
  끊기지 않습니다. 회색(채도 0.03 미만)은 건드리지 않습니다. 색조는 ±30°, 채도는 배율,
  밝기는 중간톤 위주로 움직입니다.
- 슬라이더 24개(8색 × 색조·채도·밝기). `[색상별 HSL]` 탭에서 색 칩을 고르고 세 슬라이더를 조절하며,
  고른 색만 초기화할 수 있습니다.
- **자연어**: "빨강만 살리고 초록은 차분하게", "단풍 색만 진하게", "초록색 나뭇잎 차분하게",
  "하늘 파란색만 깊게", "피부 주황기 빼줘", "노란기 빼줘", "보라색 살짝" — 색 이름과 방향
  (살리/진하게 ↔ 빼/줄여/차분하게), 강도 부사(살짝·아주·진하게)를 함께 읽습니다.
  한 문장에 두 색이 오면 각자 자기 방향으로 갑니다.
- **보정 내역 문장**: "빨강 채도를 36% 올리고, 초록 채도를 36% 낮추고, 인물 밝기를 22% 올렸어요"처럼
  영역·색 대역도 이름과 함께 문장화합니다.

## 검증

- 단위 테스트 **103개 통과** (2.0.2의 54개 → 103개). 신규: 영역·색 파싱 17, 8색 대역 수학 4,
  마스크 수학 9, 영역 내레이션·레시피 JSON·LLM 디코딩 4.
- 프래그먼트/버텍스 셰이더 `glslangValidator` 통과(#version 300 es, 0 error).
- `assembleDebug`/`assembleRelease` 성공, `apksigner verify` v2 서명 통과,
  `aapt2 dump badging`으로 `versionCode=210`, `versionName=2.1.0` 확인.
- 분할 정책: 영역·색 변경은 저장에도 그대로 들어가고, 마스크 보기 오버레이·가로 비교선은
  저장 경로에서 0으로 고정됩니다.

## 남은 확인 (실기기)

- 모델이 실제로 도는지: 사진을 열면 `영역 보정` 탭에 `마스크: MediaPipe selfie_multiclass · 인물 분리`.
- 인물 경계 페더링이 자연스러운지, 하늘이 있는 사진에서 `하늘만 파랗게`가 하늘에만 걸리는지.
- 저장 파일에서 영역 보정이 프리뷰와 같은지(원본 크기에서 마스크를 다시 만듭니다).
- 폴백 경로(비행기 모드·모델 로드 실패)에서도 슬라이더가 동작하는지.

# Lumen 2.0.2 · 말하듯 쓴 요청을 알아듣는 파서

"다양한 패턴을 알아보고 그걸 반영해줘, 예컨대 샤하게 라던가" — 요청대로 **구어체·신조어·사진 현장
표현**과 **"~하면서도 ~하지 않게" 같은 부정·상충 문장**을 크게 늘렸습니다. 사전에 50가지 패턴이
새로 들어갔고, 부정형은 새 룩이 아니라 **이미 고른 룩에 걸리는 한계**로 읽습니다.

## 새로 알아듣는 말 (50가지)

- **구어체·감성·불평 17** — 샤하게 / 샤방하게 / 뽀샤시, 포인트 (있게), 눈에 띄게·눈길을 끄는·멀리서도,
  피어나는, 느좋, 꾸안꾸, 감다살, 힙하게, 코지하게·아늑하게·포근하게, 청순하게, 여리여리,
  서늘하게, 차갑게, 나른하게, 웅장하게, 몽글몽글, 화려하게, 칙칙한데·우중충한데(불평)
- **실무·기술 구어체 6** — 누렇게 떠(노랗게 보여), 피부 맑게·트러블·잡티, 칼핀처럼·초점,
  필카 느낌(+Portra 400 65%), 디카·캠코더·Y2K 느낌, 인스타 감성·핀터레스트 느낌
- **피사체·장르 5** — 음식 맛있게, 풍경 시원하게, 야경 깔끔하게, 제품 컷처럼, 보케(배경 날리기)
- **부정·억제 22** — 화려하지 않게 / 촌스럽지 않게 / 부담스럽지 않게 / 과하지 않게(문장 전체 강도
  0.70배) / 너무 세지 않게 / 칙칙하지 않게 / 누렇게·노랗지 않게 / 파랗지·차갑지 않게 /
  하늘로 날아가지 않게 / 암부 뭉개지지 않게 / 어둡지 않게 / 너무 밝지 않게 / 밋밋하지 않게 /
  뿌옇지 않게 / 거칠지 않게 / 인위적이지 않게 / 비네팅·그레인·페이드·글로우·흑백·필름 룩 빼고

## 파서

- **부정·억제 해석** — `~하지(는) 않`, `~지(는/지도) 않`, `~지 못`, `~하지 말`, `~는 말고`,
  `~은 빼고`, `~ 없이`를 표시로 잡고, **바로 앞 6자 안의 말만** 그 표시에 딸린 것으로 봅니다.
  그래서 "확 화려하게, 근데 너무 화려하지는 않게"에서 앞의 "화려하게"는 살아남고 뒤의 부정만
  채도 상한(0.10)으로 걸립니다. 억제는 ①작은 반대 델타 ②상한/하한 ③값 해제 ④문장 전체 강도
  클램프 네 가지로 적용됩니다.
- **"~는 말고"는 반대 방향** — "부드럽게는 말고"처럼 룩 자체를 부정하면 그 룩의 반대 델타를
  0.6배로 적용합니다(부드럽게 → 조금 더 또렷하게).
- **말버릇 걷어내기** — "그거 아시죠", "뭔가", "음...", "약간 그런", "~했으면 좋겠어요", "거기",
  "근데", "그래도", "~하면서도"를 의도 매칭 전에 지웁니다. 남은 글자가 두 낱말 이상이거나 세 글자
  이상일 때만 로컬 LLM으로 넘겨서, 이미 알아들은 문장을 모델이 다시 해석하지 않게 했습니다.
- **같은 룩은 한 번만** — "눈길을 끌면서도 … 눈에 띄었으면"처럼 같은 룩을 두 번 말해도 두 배로
  적용되지 않습니다(첫 번째만).

## 로컬 LLM 프롬프트

- 시스템 프롬프트에 **말버릇 무시 규칙**, **부정·억제 규칙**("~하지 않게"는 그 파라미터를 올리지
  말라는 뜻), **상충 요구를 둘 다 지키는 규칙**을 넣고, `샤하게` / `꾸안꾸, 근데 너무 화려하지는
  않게` / `느좋하게, 살짝 필름 느낌으로` 세 가지를 few-shot으로 추가했습니다.
- 모델에 들어가기 전에 요청 문장의 말버릇을 한 번 더 덜어 냅니다(`NaturalLanguageParser.salient`).

## 사용자가 보낸 대표 문장

```
거기 깔끔하면서도 포인트가 딱 되게요. 그거 아시죠? 거기에 확 피어나는....그런 뭔가 눈길을 딱
끌면서도 그거 있잖아요. 근데 너무 화려하지는 않은....하 그래도 멀리서 봐도 딱 눈에 띄었으면 좋겠어요
```

→ 깔끔 + 포인트 + 피어나는(확 1.5배) + 눈에 띄게, 그리고 **화려하지 않게**가 채도 상한을 걸어
피사체 강조 100% · 색 정돈 75% · 명료도 57% · 활기 55% · 비네팅 22% · 글로우 27% · **채도 −16%**.
보정 내역은 "피사체 강조를 100% 넣고, 색 정돈을 75% 넣고, 명료도를 57% 올리고, 활기를 55% 올렸어요
(외 7가지)"로 나옵니다. 남은 문장은 없어서 LLM으로 새지 않습니다.

## 검증

- 단위 테스트 **68개** 통과 (`gradle :app:testDebugUnitTest`) — 구어체·부정·말버릇·복합 문장 14개를
  새로 추가
- release/debug APK 빌드 및 `apksigner verify` 통과 (버전 2.0.2 / versionCode 202)

## 실기기에서 확인할 것

- "샤하게", "꾸안꾸", "포인트 있게" 같은 빠른 요청 칩이 붙은 새 말을 실제로 보정하는지
- "너무 화려하지는 않게"를 단독으로 넣었을 때 채도가 내려가고 카드에 문장이 뜨는지
- 로컬 LLM을 켠 상태에서 위 대표 문장이 모델로 넘어가지 않고(전부 규칙이 읽음) 바로 적용되는지

# Lumen 2.0.1 · 자연어 비파괴 사진 보정

실기기에서 보내 주신 스크린샷과 네 가지 요청을 반영한 업데이트입니다.

## 고친 것

- **키보드가 프롬프트 입력창을 가리던 문제**
  targetSdk 35의 edge-to-edge 환경에서 창이 키보드 인셋을 피하지 못했습니다.
  액티비티를 edge-to-edge로 열고, 화면 아래에 `navigationBars`와 `ime` 중 **큰 쪽**만큼의
  여백을 주도록 바꿨습니다. 키보드가 올라오면 프리뷰가 줄어들고 입력창·전송 버튼이
  키보드 바로 위에 남습니다. 입력 중에는 칩·빠른 요청·하단 도구 줄을 잠시 접어 프리뷰를 넓게 씁니다.
- **Before & After 가로선 비교**
  프리뷰 위에 드래그할 수 있는 얇은 가로선과 중앙 핸들, `BEFORE`/`AFTER` 뱃지를 그렸습니다.
  셰이더에 `uSplitEnabled`·`uSplitY`를 추가해 **선 위쪽은 보정 전 원본, 아래쪽은 보정 후** 픽셀을
  그립니다(57종 룩·그레인·비네팅까지 모두 포함). 프리뷰 오른쪽 위 `가로 비교` 칩으로 언제든 켜고 끄며,
  선을 위아래로 끌면 실시간으로 비교됩니다. **저장 파일에는 비교선이 들어가지 않습니다** —
  내보내기는 언제나 전체 보정 이미지입니다.
- **보정 내역 메시지**
  요청을 적용할 때마다 `EditRecipe`의 **실제 전/후 값 차이**를 읽어 한국어 문장을 만듭니다.
  예: `채도를 18% 올리고, 하이라이트를 20% 낮추고, 색온도를 따뜻하게(25%) 했어요.`
  입력창 바로 위 반투명 카드에 표시되고, 슬라이더를 직접 움직여도 그 값이 문장으로 나옵니다.
  문장은 모델의 추측이 아니라 화면에 실제로 적용된 값에서 나오므로 프리뷰와 항상 일치합니다.
- **사전에 없는 표현의 로컬 LLM 추론**
  - 룰 파서가 아무것도 매칭하지 못하면 곧바로 로컬 LLM 경로로 넘깁니다. 룰이 일부만 읽은 문장은
    남은 부분만 모델이 이어서 해석합니다.
  - 시스템 프롬프트를 다시 썼습니다: 조절 가능한 모든 파라미터 이름, `-1.0~+1.0` 상대 델타 범위,
    대표 필름 룩 예시, 그리고 "사전에 없는 추상적·감성적 표현이라도 사진학적으로 해석해
    **서로 다른 파라미터 2개 이상**과 한국어 `summary`를 JSON으로 내라"는 지침을 넣었습니다.
  - **채팅 템플릿 이중 적용을 없앴습니다.** MediaPipe `.task` 번들이 Qwen 템플릿을 안에서 입히는데
    프롬프트에도 `<|im_start|>…`를 넣어 두 번 적용되고 있었습니다. 이제 프롬프트는 평문입니다.
  - `LlmRecipeDecoder`를 관대하게 보강했습니다: 잘려 나간 JSON의 괄호 닫기, 작은따옴표·따옴표 없는 키·
    끝 쉼표 허용, 숫자 문자열(`"0.35"`, `"-35%"`)과 퍼센트 값 해석, 한국어 파라미터 이름과
    중첩 그룹(`{"색감":{"채도":0.3}}`) 인식, 새어 나온 `<|im_start|>` 토큰 제거.
  - 모델이 룩을 제안하면 **레시피에도 반영**합니다(이전에는 텍스처만 올리고 선택은 되지 않았습니다).
  - 모델을 아직 내려받지 않았으면 안내 카드에
    "사전에 없는 표현이에요. 상단 설정(⚙️)에서 로컬 LLM(547MB)을 내려받으면 자유로운 문장도
